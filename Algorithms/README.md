## 🎯 算法学习路线

```
第1阶段：排序与搜索（2周）
  理解时间复杂度：O(1) < O(log n) < O(n) < O(n log n) < O(n²)

第2阶段：基础数据结构（3周）
  链表 → 栈/队列 → 树/堆 → 哈希表

第3阶段：算法思想（4周）
  分治 → 贪心 → 动态规划 → 图算法

第4阶段：嵌入式算法应用（持续）
  状态机 → 滑动窗口 → 数字滤波器 → 简单神经网络推理
```

---

## ⏱️ 时间复杂度速查

| 算法 | 最好 | 平均 | 最坏 | 空间 |
|------|------|------|------|------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) |
| 二分搜索 | O(1) | O(log n) | O(log n) | O(1) |
| BFS/DFS  | - | O(V+E) | O(V+E) | O(V) |
